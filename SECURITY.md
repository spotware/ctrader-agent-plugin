# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in the cTrader plugin, do not open a public GitHub issue. Report it privately through one of these channels:

- **GitHub Security Advisories** (preferred): [Report a vulnerability](<https://github.com/spotware/ctrader-agent-plugin/security/advisories/new>).
- **Email**: send the report to `support@ctrader.com` with the subject line `Security report: ctrader-agent-plugin`.

We acknowledge receipt within 5 business days and give an estimated remediation timeline after triage.

## Scope

This policy covers the contents of the [`spotware/ctrader-agent-plugin`](<https://github.com/spotware/ctrader-agent-plugin>) repository: the plugin manifests, the MCP server declarations and the `ctrader-analytics` skill.

Vulnerabilities in cTrader platform components, including the cTrader MCP server, cTrader Desktop, the cTrader mobile apps and the cTrader web platform, are out of scope for this repository. Report those through the official cTrader support channel at [spotware.com](<https://www.spotware.com/>).

## Supported Versions

Only the latest version of the plugin, the one on the default branch of this repository, receives security updates.

## Disclosure Policy

We follow coordinated disclosure. Once a fix is available, we agree on a public disclosure timeline with the reporter, typically 30 to 90 days. We credit reporters in the changelog unless they prefer to stay anonymous.
